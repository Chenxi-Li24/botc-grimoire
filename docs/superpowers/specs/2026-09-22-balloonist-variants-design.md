# 气球驾驶员新旧版与逐夜信息历史设计（待实施）

## 目标与边界

说书人在含气球驾驶员的剧本中，开局前明确选择新版或旧版规则；每次夜晚只向气球驾驶员发送一名玩家的座位号（旅行者用独立标识）。说书人能回看每夜发送的目标、当时的真实角色类型和为这次判定采用的登记类型；玩家只能回看本人实际收到的夜次和目标，避免遗忘且不泄漏魔典信息。本设计只记录和计划，不修改正在进行的局。

## 规则来源

- [官方气球驾驶员页面](https://wiki.bloodontheclocktower.com/Balloonist)与[2024-06-27 变更记录](https://wiki.bloodontheclocktower.com/Changelog)：新版每夜指向一名与上次所给玩家**登记的角色类型**不同的玩家，外来者 +0 或 +1；旧版依次给未展示过的类型，用尽停止，外来者固定 +1。两版均只向玩家展示具体玩家，而不展示类型。
- [官方陌客页面](https://wiki.bloodontheclocktower.com/Recluse)：陌客即本项目的 `recluse`，可能登记为外来者、爪牙或恶魔，即使死亡也可能如此。间谍也可能登记为镇民或外来者；登记是单次判定，不改动真实角色。醉酒、中毒、涡流及其他信息干扰另行记录。
- 镇民、外来者、爪牙、恶魔为四个基础类型；若旅行者在场，可作为第五类候选，旧版来源数据也明确列有旅行者。旅行者使用其现有独立标识／名字展示，不能虚构普通座位号。若某定制剧本有单独文本，必须以剧本规则显式覆盖，不暗中混用。

## 开局选择

在说书人「开局设置」剧本下方，只有所选剧本包含气球驾驶员时显示「气球驾驶员规则」卡片。新版、旧版均不预选，必须明确点击；新版再明确选外来者 +0 或 +1，旧版固定 +1。现有「应用新配置」确认框同时列出剧本、人数、版本与外来者调整，改配置仍会清空座位和分配。开局后版本锁定；一个剧本一次只启用一个版本，不把两版角色同时放入发牌池。

后端在本局配置和存档里持久化 `balloonist_version` 与 `balloonist_outsider_delta`，并按版本展示「气球驾驶员（新版／旧版）」文案与夜晚提示。配比调整仅在气球驾驶员实际在场时生效。保留来源 JSON 原件，运行时套用版本差异。旧存档没有版本字段时不臆造历史、不改变进行中旧局的手动行为；下一次重新配置剧本时必须显式选择。

## 夜晚执行与追溯

每次气球驾驶员步骤在说书人右侧显示本局前夜时间线、上一条**有效**信息的登记类型，以及当前可选玩家。说书人选择一名玩家（普通座位号，或在场旅行者的独立标识／名字）；若目标是陌客／间谍，先明确选择本次按真实类型还是按允许的其他类型登记。候选筛选使用这次登记类型：新版与上次有效信息不同；旧版不得选已经展示过的类型。新版类型可隔夜复用，目标玩家也可隔夜重复；旧版类型用尽后结束后续步骤。已死玩家仍可被指向。

在发送前确认预览「第 N 夜 → X 号／旅行者标识；真实类型；本次登记类型；登记来源；是否受醉酒／中毒／涡流等影响」。实际发送给玩家的载荷只有夜次和玩家标识。每次发送以不可变事件保存：夜次、行动座位、接收身份、目标座位或旅行者 ID、真实角色及类型快照、登记角色及类型快照、登记原因、状态快照、给出的内容、规则符合性与信息真假标记、时间、撤回关系。陌客合法登记成另一类型不自动等于“错误信息”；真实类型、登记类型、信息真假是三条不同事实。角色后来转变也不能回写旧记录。

说书人历史按夜次列出上述关键字段，并能展开来源与撤回／更正记录；玩家历史只列本人各夜**实际收到的座位号／旅行者标识**（以及必要的「已撤回」提示），绝不含真实角色、登记类型、候选名单、真假或异常状态。若同夜更正，保留曾发送和更正后的两条记录，不能假装玩家没见过前一条。后端按当前会话／座位领取权限投影私密历史，重连后保持可见；换座或撤销会话时不可仅凭座位号泄漏前任玩家信息。线下无人领取的座位仍可正常执行步骤，待合法领取后才展示该座位应收到的信息。

醉酒／中毒时允许说书人选择不满足正常类型顺序的信息，并要求标明这条信息按当时能力效果是对还是错；涡流的强制错误不能被标成正确。缺少可判定候选时提示人工裁决，不能自动捏造一个玩家。夜序回退只是浏览；真正撤销通过已有事件撤销机制，撤回信息不再作为后续类型约束依据，审计历史仍保留。

## 实施顺序与验收（尚未执行）

1. 测试先行：两版夜序、+0／+1 配比、旧局缺字段、陌客／间谍登记、异常状态、撤回与私密投影。
2. 扩展开局配置 API、存档和剧本元数据；说书人开局设置加入条件式版本选择及确认文案。
3. 为两版建立独立的气球驾驶员规则判定器和逐夜事件；复用现有信息发送、真伪与撤销通道，不依赖自由文本结果。
4. 说书人夜晚操作区加入选人、单次登记、发送预览及逐夜历史；玩家页加入只含本人所收目标标识的历史列表。
5. 跑后端／前端回归与重连、权限、旧局兼容测试；备份现场数据后再部署，不在正在验收的局里试写。

验收样例：新版第 1 夜给 2 号（登记外来者）、第 2 夜给 5 号（登记镇民）、第 3 夜可再给 2 号（登记外来者）；旧版不能在类型用尽前重复登记外来者。若 2 号是陌客，说书人历史同时保留「真实外来者／当夜登记恶魔」，玩家只看到「第 1 夜：2 号」。
